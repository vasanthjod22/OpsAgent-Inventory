# OpsAgent — AI Back-Office Manager

AI-powered back-office management system for small 
service businesses (logistics, construction, utilities).

## Features
- Finance Snapshot with AI analysis
- GRN OCR Upload (printed + Tamil handwritten)
- Smart Inventory with auto stock updates
- Conversational AI Chat over business data

## Tech Stack
- React 18 + Vite
- Tailwind CSS
- Gemini AI API (free tier)
- localStorage for data persistence

## Setup

1. Clone the repo
2. npm install
3. Copy .env.example to .env.local
4. Add your Gemini API key
5. npm run dev

## Deploy to Vercel
1. Push to GitHub
2. Connect repo on vercel.com
3. Add VITE_GEMINI_API_KEY in Vercel environment variables
4. Deploy!
